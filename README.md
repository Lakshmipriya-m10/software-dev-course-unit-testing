Our program has three methods:
    - Calculate Discount: This function checks for the provided values to be numbers first, if they are not, the function returns null.  
         After validating the input, the function then calculates the final value with the formula: 

         x = a - (a * (b - 100))

         Once calculated, it returns the value in a variable named discountPrice. 


    - Filter Products: This function first checks to ensure the provided values are valid, and then filters items by value.


    - Sort Inventory: This function is designed to sort the inventory by one of the available keys in the object. It first checks that
        both provided values are an array and string respectively. As written, it is designed to sort intventory in ascending alphabetical order.
